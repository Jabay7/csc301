# CSC 301 Field Guide

An interactive study guide for a second course in data structures, following
Sedgewick & Wayne, *Algorithms* 4th edition.

**Live: https://jabay7.github.io/csc301/**

**Final Lab (hand-trace drills + mock final): https://jabay7.github.io/csc301/final-lab.html**

One self-contained HTML file. No build step, no dependencies, no tracking, no
analytics, no cookies — nothing is collected and nothing leaves your browser.
Flashcard and quiz progress is saved in `localStorage`, so it stays on your own
device.

## What's in it

- **Sixteen topic sections** — Java essentials and Big-O, then symbol tables,
  binary search trees, 2–3 and left-leaning red–black trees, heaps, hash tables,
  undirected and directed graphs, minimum spanning trees, union-find, and tries.
  Each has a plain-English walkthrough, analogies, and *Where people go wrong*
  boxes built from published research on what students in this course actually
  get wrong.
- **Six visualizers** — insert into a BST and watch it degrade on sorted input,
  step through red–black rotations, watch a max-heap swim and sink, cause hash
  collisions under both chaining and linear probing, run DFS against BFS on the
  same graph, and compare naive quick-union with weighted + path compression on
  identical input.
- **110 flashcards** across 10 decks, scheduled with FSRS — the algorithm behind
  modern Anki — plus streaks, XP and leech detection.
- **8 quiz banks**, graded instantly, with an explanation for every answer
  including why the wrong ones are tempting.
- **Exam technique** — eight fully worked hand-traces in the format exams use,
  and a one-page cheat sheet of every cost, rule and decision.

## How to use it

Predict the result on paper, *then* press the button. A visualizer you only
watch teaches you nothing — it's for checking work you already did. Dunlosky's
review of ten study techniques found only two with high utility: practice
testing and distributed practice. Re-reading rated low.
